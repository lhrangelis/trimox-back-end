# trimox-back-end

Back-end do **Trimox**, um software de gestão para barbearias e salões de beleza. O front-end fica em [trimox-front-end](https://github.com/lhrangelis/trimox-front-end).

A stack proposta é **Supabase**: Postgres com Row Level Security, Auth, Storage, Edge Functions e jobs agendados, hospedado na região São Paulo.

- A análise do front-end, a comparação de stacks e a arquitetura proposta estão em [`docs/ARQUITETURA.md`](docs/ARQUITETURA.md).

O repositório ainda está na fase de planejamento. As migrations, os testes e as Edge Functions entram na fase 0 do roteiro.
